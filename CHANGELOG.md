# Change Log

All notable changes to the "vscode-misshit-unofficial" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [0.0.1] - 2025-05-01

### Added
- Initial release of MISS_HIT unofficial extension
- Basic integration with mh_lint and mh_style
- Automatic checking of MATLAB files on save
- Manual lint and style checking via command palette
- Real-time display of diagnostics with appropriate severity levels
- Support for running `mh_style --fix` to automatically fix style issues
- Precise highlighting of code issues with detailed messages and error codes
